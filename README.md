Edit `index.html` and replace:
- [YOUR NAME]
- [YOUR EMAIL]
- [LINKEDIN URL]
- [X PROFILE URL]
- [City / Remote]
- [Start Date] and [End Date]
- [YEAR]

Add genuine work samples and verified metrics. Do not publish confidential company material. Make sure every claim accurately reflects your contribution.

## Publish with GitHub Pages
This repository uses the GitHub Pages user-site naming format: `dolenhatnam-cyber.github.io`.

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the Pages deployment to finish.

Expected website address: https://dolenhatnam-cyber.github.io/
